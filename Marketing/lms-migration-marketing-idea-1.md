# LMS Migration Marketing Idea

## Core positioning
- Migrate legacy LMS data into ILS as an upgrade, not a straight import.
- Emphasize that traditional LMS systems are content-driven and siloed, while ILS is a relational learning system with cross-course intelligence.
- Position ILS migration as a path from structure and content into an intelligence-enabled curriculum.

## Differentiators
- Most migration efforts stop at structure or content; ILS goes further by unlocking outcomes, rubrics, competencies, and analytics.
- The intelligence layer is the real value driver and the competitive advantage.
- We don’t just move data; we interpret and upgrade it.

## Sales messaging
- Migrate schools from Moodle, Canvas, CSV, and other systems into a smarter curriculum platform.
- Support staged migration: easy structure import first, then content, then intelligence.
- Highlight that ILS turns messy legacy learning data into meaningful learning signals.

## Pain points to call out
- LMS migrations fail because outcomes are inconsistent, rubrics are often missing, and grading logic is non-standard.
- The greatest challenge is translating source systems into ILS’s horizontal intelligence layer.
- Schools typically have unstructured courses, partial rubric usage, and outcomes that don’t map cleanly.

## Core insight
- "Our system is stronger than most LMS because of the intelligence layer. We don’t just import data — we upgrade it."

## Suggested copy flow
- External LMS data → Importer service → Mapping layer → ILS schema
- Add a human review/repair step for ambiguous or low-quality source data.

## Positioning line
- "Move legacy LMS content into ILS with a migration that preserves structure, imports content, and elevates intelligence."
