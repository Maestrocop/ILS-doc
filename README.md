ILS Documentation (MkDocs)

This repository contains the documentation site for the Intelligent Learning System (ILS).

IMPORTANT: This is the documentation project only. Do NOT place or modify application source code here — application code lives in the `ILS-dev` repository.

To preview the docs locally:

1. Install Python 3.8+ and pip.
2. Install MkDocs and Material theme:

   pip install mkdocs-material

3. From this folder, run:

   mkdocs serve

Open http://127.0.0.1:8000 in your browser.

When ready, we'll populate the manuals section-by-section in `docs/`.
