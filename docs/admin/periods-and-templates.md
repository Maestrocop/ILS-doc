# Periods and Period Templates (Admin Guide)

## Understanding Periods

Academic periods represent time blocks in your institution:
- **Institution-level periods**: Academic years, semesters, or quarters (e.g., "2025–2026", "Semester 1")
- **Course-specific periods**: Teaching blocks or modules for a specific course (e.g., "Blok 1", "Blok 2")

Both types are managed in the Academic Calendar and are used by the Curriculum Composer and timetable system.

## Setting Up Periods

### Step 1: Create Institution Calendar

1. Go to **Settings → Academic Calendar**
2. Click **Create Academic Year** (e.g., "2025–2026")
3. Add child periods under the year with concrete start and end dates
   - Example: "Semester 1 (Sep 2025 – Feb 2026)"
   - Example: "Semester 2 (Mar 2026 – Aug 2026)"
4. Save

### Step 2: Apply Period Templates (Quick Setup)

If you want to set up course-specific teaching blocks quickly:

1. Open the Curriculum Composer for a course
2. Go to the **Periods** step
3. Click **Apply Template** and select a template:
   - **Quick Template**: 5-period year (for rapid onboarding)
   - **Standard Template**: 44 weekly periods (for detailed planning)
4. Click **Add** to create the periods

### Step 3: Or Create Periods Manually

1. In Curriculum Composer → **Periods step**
2. Click **Add Period** to create individual teaching blocks for this course
3. Give each a name and set start/end dates
4. Save

## Key Rules

- **Always add dates**: Every period must have a start and end date — never leave dates blank
- **Templates save time**: Use Period Templates to create standard structures in one click
- **Admin sets institution calendar first**: Designers should select periods from the Academic Calendar, not create new ones in the Composer

## Quick Tips

- Use the Quick Template for new courses (saves 5 minutes)
- Use the Standard Template when teachers need weekly session precision
- Institution-level periods (years, semesters) are managed by Admin only
- Course-specific periods are created by Designers in the Curriculum Composer or via templates
