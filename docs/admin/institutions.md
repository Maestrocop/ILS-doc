# Institutions

Institutions are the top-level organizations in the system (schools, colleges, or networks). Campuses and courses belong to institutions.

## What you can do

Go to **Institutions** in the admin menu to:

- View all institutions
- Create a new institution
- Edit institution details
- Archive institutions that are no longer active

## Institution details

When you create or edit an institution, you'll fill in:

- **Name** — the full institution name
- **Code** — short identifier for reports
- **Description** — optional notes
- **Location** — city or region
- **Website** — institution URL
- **Contact email** — main contact address
- **Logo URL** — optional logo image link
- **Status** — active or inactive

## Admin workflow

1. Open the Institutions page.
2. Create or edit the institution metadata.
3. Save the institution to make it available for campus and course assignment.
4. Delete obsolete institution records after verifying no active campuses remain.

## Notes

- Institution management is restricted to admin users in the UI.
- The institution entity is the root of the curriculum hierarchy and is referenced by campuses.
