# Passing but Outcome Gap — Alert type

This admin note describes the proposed alert type: "Passing but outcome gap".

## Definition

- Trigger: Student overall grade ≥ passing threshold AND at least one outcome mastery score < diagnostic threshold.
- Purpose: Surface students who are passing but have critical skill deficits.

## Example alert text

"Passing but outcome gap — SM-01 = 3.3/10 (below diagnostic threshold)."

## Admin considerations

- Configureable thresholds: passing grade and outcome diagnostic threshold.
- Reporting: include the alert in class-level reports and the Progression Review side-panel.
