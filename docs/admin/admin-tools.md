# Admin Tools & Utilities

This page describes the core admin-facing tools available in ILS and where to find them.

## Who uses this

School administrators, system operators, and site maintainers.

## Where to find admin tools

Admin menu (sidebar) pages include:
- Users
- Classes
- Institutions
- Periods
- Academic Calendar
- Audit Logs
- Settings

## Common admin responsibilities

- Manage Institutions, Campuses, Courses, and Periods
- Maintain Academic Calendar events
- Oversee user accounts and role assignments
- Manage class-teacher mappings
- Review audit logs for administrative actions

## Operational notes

- Admin deletions are soft (records are archived) to preserve historical auditability
- Recovering deleted data requires admin support
