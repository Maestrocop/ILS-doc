# Curriculum Structure Guidance

Clear naming prevents confusion between curriculum structure (what) and the academic calendar (when).

## The Problem

The word "Period" is used for two different concepts:

- **Academic Period** — a dated calendar range (Semester 1, Period 3)
- **Curriculum Period** — a curriculum grouping or block (Foundation, Theme A)

Using the same term creates confusion for designers, admins, and teachers.

## Key Principle

Separate the WHAT (curriculum structure) from the WHEN (academic calendar). Keep distinct, clear names in the UI.

## Recommended Language

- Use "**Block**" or "**Theme**" for curriculum groupings (the learning structure)
- Use "**Period**" or "**Term**" for dated academic calendar ranges
- Use "**Schedule**" or "**Timetable**" for when/where classes meet

## Why This Helps

- Designers won't accidentally create undated calendar entries when they mean to group modules
- Admins will understand that scheduling belongs to the Academic Calendar UI
- Timetables and session generation become clear because curriculum structure is separate from scheduling

## Helper Text

Add guidance near curriculum controls:

> "Organise modules into curriculum blocks or themes. Blocks help structure the learning journey and group related modules. Blocks do not define dates or schedules. Scheduling is managed separately through the Academic Calendar and Timetable."
