# PDCA Poster — One-page quick reference

Plan-Do-Check-Act (PDCA) — continuous improvement loop for ILS

Plan
- Design curriculum in Curriculum Composer (blocks, modules, outcomes)
- Set goals and success metrics (e.g., clarity >= 4, engagement >= 3)

Do
- Deliver sessions (timetable → sessions)
- Teachers teach and optionally request session feedback

Check
- Collect session feedback (clarity, engagement, comments)
- Run analytics: per-session, per-module, per-teacher trends

Act
- Update curriculum: adjust sequences, rubrics, learning activities
- Coach teachers and re-run PDCA on updated content

Quick tips
- Keep session feedback short (3 questions) to maximise response rate
- Surface small-N flags in Intelligence Hub for rapid intervention
- Use module-level surveys for deeper evidence before curriculum changes

Visual (ASCII)

  Curriculum (Plan)  →  Teaching (Do)  →  Feedback (Check)  →  Update (Act)

Add this poster to onboarding materials and admin dashboards as a reminder of the loop.
