# Import Report — Requirements

Provide a comprehensive, downloadable report after each import.

Report contents:
- Summary counts: Imported, Updated, Skipped, Errors
- Row-level details: row_number, status (Imported/Updated/Skipped/Error), message
- Downloadable CSV and JSON versions

UX notes:
- Provide direct links from errors to the original uploaded row in Preview where possible
- Allow re-run of failed rows only (partial re-import)
