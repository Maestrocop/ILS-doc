# Rubrics & Criteria

Rubrics are grading tools that connect student work to learning outcomes. Use the Rubrics page to create grading criteria and link them to outcomes.

## What you can do

Go to **Rubrics** in the admin menu to:

- View all rubrics
- Create new rubrics with criteria and rating levels
- Edit rubric criteria
- Link criteria to learning outcomes
- Set pass thresholds and rubric weights

Go to **Criteria Bank** to:

- Review all criteria across all rubrics
- Check which outcomes are linked to which criteria
- Identify duplicate or similar criteria

Go to **Mapping Matrix** to:

- See assignment-to-outcome coverage across the curriculum
- Verify that assignments assess the right outcomes
- Check that outcome coverage is balanced across modules

## Rubric authoring

When you create or edit a rubric, you'll:

1. Add a rubric name and description
2. Add criteria (what you're assessing)
3. Define rating levels for each criterion (e.g., Excellent, Good, Needs Work)
4. Attach criteria to learning outcomes
5. Set pass thresholds and weights
