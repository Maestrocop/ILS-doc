# Student Support Module

## Advisor Assignment

You can assign advisors to students and manage their support relationships. Each student can have multiple types of advisors (mentor, counselor, career advisor, or internship coach).

### How to assign advisors to students

- Go to **Student Advisors** page (admin only)
- Select a class to see all enrolled students
- Pick an advisor and advisor type
- Click assign — all students in the class get the assignment in one click
- The system skips students who already have that advisor type for that class
- You can edit individual student assignments anytime

### Advisor types and roles

- **Mentor** — Academic support; day-to-day check-ins
- **Counselor** — Wellbeing and personal guidance
- **Career Advisor** — Career planning and graduation prep
- **Internship Coach** — Internship supervision and support

### Your tasks as an advisor

- Find a student's primary advisor on the student card
- View your active caseload filtered by your name
- Manage handovers by setting start/end dates when reassigning advisors
- See advisor badges in class listings to track who is assigned
