# Audit Logs

The Audit Logs page shows you who made changes in the system and when.

## What you can do

Go to **Audit Logs** in the admin menu to:

- View recent system events
- Filter by user, date, and event type
- Inspect details for changes made in the system

## Workflow

1. Open Audit Logs
2. Search for relevant change events
3. Review who made changes and when

## Why use Audit Logs

- Essential for compliance and troubleshooting
- Confirm configuration changes
- Track user actions
- Investigate unexpected changes
