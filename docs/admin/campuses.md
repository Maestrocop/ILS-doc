# Campuses

Campuses represent physical or organizational teaching locations. Each campus has its own reporting rules that control how teacher dashboards and student progress reports behave.

## What you can do

Go to **Campuses** in the admin menu to:

- View all campuses in your institution
- Create a new campus location
- Edit campus details (name, code, city, address)
- Set reporting rules (thresholds for teacher dashboards)
- Archive campuses that are no longer active

## Campus details

When you create or edit a campus, you'll fill in:

- **Name** — the campus display name
- **Code** — short identifier for reports
- **City** and **Address** — location information
- **Description** — optional notes about the campus
- **Institution** — which institution owns this campus
- **Status** — active or inactive

## Reporting rules

Reporting rules control how teachers see student progress and alerts. You can set:

- **Low activity days** — how many days without activity before a student is flagged
- **Success threshold** — minimum score to show green in heatmaps
- **Reteach threshold** — score below which the system suggests reteaching

These thresholds affect:
- Teacher heatmaps
- Classroom intelligence panels
- Student cockpit views

## Admin workflow

1. Create or edit campus records to define teaching locations.
2. Assign campuses to institutions.
3. Use the reporting rules editor to configure campus thresholds.
4. Keep campus metadata current to ensure class reports use the correct context.
