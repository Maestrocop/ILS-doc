# Setup Health

The Setup Health page provides health checks for the ILS environment.

## What you can do

Go to **Setup Health** in the admin menu to:

- View system health status
- Surface issues with system configuration or missing data
- Confirm the installation is ready for use
- Identify warnings or failed checks

## Workflow

1. Navigate to Setup Health
2. Review the health check results
3. Address any warnings or failed checks

## When to use it

- During initial deployment
- Troubleshooting system issues
- Validating application state before production use
