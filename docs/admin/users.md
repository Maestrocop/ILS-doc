# Users

The Users page lets you manage all system accounts, assign roles, and control access to features.




## What you can do

Go to **Users** in the admin menu to:

- View all user accounts
- Search and filter by role or campus
- Create new accounts for staff or students
- Edit user details (name, email, campus, role)
- Assign roles (admin, teacher, student, coordinator, etc.)
- Archive users who no longer need access
- Reset passwords for users who are locked out

## Workflow

1. Open the Users page
2. Search for a user or create a new account
3. Update the user's profile, campus assignment, or role set
4. Archive users who should no longer be active

## User roles

**Admin** — manages users, classes, enrollment, and settings

**Coordinator** — manages assigned courses and enrollment only

**Teacher** — delivers classes, grades assignments, views student progress

**Student** — accesses curriculum, assignments, and progress views
