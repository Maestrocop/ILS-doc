# Themes

Themes are high-level learning categories that help organize modules and courses around common topics or curriculum areas.

## What you can do

Go to **Themes** in the admin menu to:

- View all learning themes
- Create new themes
- Edit theme names and descriptions
- Archive themes that are no longer used

## How themes work

- Themes group modules and learning outcomes
- They appear in reporting and curriculum maps
- Teachers use them to see cross-module connections
