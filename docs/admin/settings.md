# Settings & Reporting Rules

The Settings page manages admin settings and campus-level reporting thresholds.

## What you can do

Go to **Settings** in the admin menu to:

- View and manage campus-level intelligence thresholds
- Configure reporting rules for teacher-facing reports
- Update teaching methods and calculation settings
- Manage outcome categories

## Reporting Rules

Campus reporting rules control teacher-facing intelligence thresholds. Each campus can have custom thresholds for:

- Low activity days (1-30 days)
- Success threshold (0-10 points)
- Re-teach threshold (0-100%)

### Workflow

1. Open the Settings page and select the Reporting Rules tab
2. Choose the campus to configure
3. Update the campus thresholds
4. Save the rules and confirm they apply to teacher reports

### How it helps

- Reporting rules are campus scoped
- Teacher reports (Heatmap, Classroom Intelligence, Student Cockpit) use these thresholds
- Missing campus rules fall back to safe default values
- Thresholds align with local academic policies
