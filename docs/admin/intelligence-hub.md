# Intelligence Hub — Program & Curriculum Signals

The Intelligence Hub displays program and curriculum performance metrics to help identify areas requiring attention.

## What you see

**Program Overview:**
- Active student count per program
- On-track vs at-risk student counts
- Average score and trend direction
- Overall program health snapshot

**Modules Below Pass Mark:**
- For each program, percentage of modules below the pass threshold (default 55%)
- Identifies structural curriculum concerns
- Shows module-level assessment issues

## How to use it

Read the two tables together to diagnose issues:

**If modules are failing but cohort health is good:**
- Investigate curriculum design and assessments
- Review module difficulty and alignment
- Consider curriculum updates

**If cohort health is poor but modules mostly pass:**
- Investigate student selection and preparation
- Review student support systems
- Consider external or cohort-specific factors

**If both are strong:**
- Program is healthy; monitor for changes

## Small sample note

Programs with very few active students are omitted from the Program Overview to avoid noisy data. If a program appears in "Modules Below Pass Mark" but not in "Program Overview", it indicates a small cohort.

## Who uses this

- Program managers
- Curriculum designers
- Education managers
- Coordinators
