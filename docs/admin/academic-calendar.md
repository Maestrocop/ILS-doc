# Academic Calendar

The Academic Calendar manages institution-wide dates that affect everyone: holidays, exam periods, semester boundaries, and registration windows.

## What you can do

Go to **Academic Calendar** in the admin menu to:

- View all academic events
- Create new academic events (holidays, exam periods, breaks, registration windows)
- Edit event details
- Delete events that are no longer needed

## Event types

You can create these types of academic events:

- **Holiday** — institution-wide days off
- **Exam period** — scheduled exam windows
- **Semester start/end** — term boundaries
- **Break** — short breaks between terms
- **Registration** — enrollment windows

## Creating an event

When you create an academic event, you'll set:

- **Event type** — what kind of event this is
- **Title** — name of the event (e.g., "Winter Break")
- **Description** — additional details
- **Start date** — when the event begins
- **End date** — when the event ends (for multi-day events)
- **Institution** — which institution this event applies to
- **Academic year** — which year this event belongs to

## How it works

- Academic events appear on the unified calendar for all users
- Multi-day events (like semester breaks) automatically expand to show every day
- Deleting an event archives it (historic calendar data remains available)
