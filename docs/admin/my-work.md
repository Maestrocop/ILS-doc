# My Work

My Work is the teacher-facing submission workspace where you manage student submissions across your classes.

## What you can do

Go to **My Work** in the admin menu to:

- Filter submissions by class and assignment
- View submission status and grading progress
- Open individual submissions for rubric grading
- Identify submissions that need teacher action
- Review pending, graded, and revision work

## Workflow

1. Open My Work
2. Select the class or assignment you want to grade
3. Review submission statuses and prioritize ungraded work
4. Open a submission to score it in the grading panel

## How it helps

- Central place to manage all your grading
- Submission-centric grading workspace
- Distinct from Student Cockpit (which focuses on student action prioritization)
- Useful for teachers who need to track grading progress across classes
