# Mapping Matrix

The Mapping Matrix shows assignment-to-outcome coverage across the curriculum.

## What you can do

Go to **Mapping Matrix** in the admin menu to:

- View assignments along with their linked outcomes
- Identify coverage gaps and overlaps
- Confirm assessment balance across modules
- Find assignments missing linked outcomes
- Find outcomes that lack assessments

## Workflow

1. Open Mapping Matrix
2. Review the mapping grid for assignment/outcome coverage
3. Identify gaps where assignments need outcomes or outcomes need assessments

## When to use it

- Most valuable after outcomes, rubrics, and assignments have been created
- Essential planning and validation tool for curriculum designers
- Use during curriculum alignment reviews
