# Course Builder

The Course Builder is an authoring workspace where you can design and preview the student course experience.

## What you can do

Go to **Course Builder** in the admin menu to:

- Select courses and modules
- Review course content as students will see it
- Verify student course navigation and structure
- Preview assignments and module flow

## Workflow

1. Open Course Builder
2. Browse available courses and modules
3. Select a course to preview
4. Review the student learning path
5. Make adjustments as needed

## Why use Course Builder

- Verify student navigation before publishing
- See exactly what students will see
- Bridge between admin configuration and student experience
