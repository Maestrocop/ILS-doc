# Courses & Modules

Courses are the named curriculum offerings. Modules are the units of delivery within those courses.

## Managing Courses

Go to **Courses** in the admin menu to:

- View all courses
- Create new courses
- Edit course details (title, code, description, status)
- Browse archived courses

## Managing Modules

Go to **Modules** in the admin menu to:

- View all modules
- Create new modules
- Edit module details
- Link outcomes and themes to modules
- Select teaching methods
- Add assignments
- Map modules to parent courses

## Workflow

1. Create or update the course record
2. Create modules for the course
3. Link outcomes, themes, and teaching methods to each module
4. Add assignments to modules
5. Publish modules to teachers

## How they work together

- **Courses** group modules and provide overall context
- **Modules** are the primary unit of curriculum delivery
- Teachers and students work primarily with modules
- Modules can be published to teachers once their outcomes and assessments are configured
