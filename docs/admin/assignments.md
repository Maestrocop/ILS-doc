# Assignments

Use the Assignments page to create and manage student work items across courses and modules.

## What you can do

Go to **Assignments** in the admin menu to:

- View all assignments
- Search and filter assignments by course or module
- Create new assignments
- Edit assignment details (title, description, due dates, rubrics)
- Archive assignments that are no longer active

## Assignment details

When you create or edit an assignment, you'll set:

- **Title** and **Description** — what the assignment is about
- **Module** — which module this assignment belongs to
- **Due date** — when students must submit
- **Scoring mode** — rubric-based, points-based, or pass/fail
- **Linked rubric** — the grading tool teachers will use
- **Linked outcomes** — which learning outcomes this assignment assesses

## Allowed submission file types

As of October 2026, student submission uploads are restricted to **PDF, plain text (.txt), JPG, and PNG** by default — these are the formats the AI grading assistant ("Ibn Rushd") can actually read. A handful of assignments with a genuine spreadsheet deliverable (e.g. one requiring an Excel worksheet) keep a per-assignment exception for `.xlsx` — those submissions just won't be AI-readable and are graded manually. Resources (the teaching-material library, separate from student submissions) have a wider allowed list: the same four formats plus Word/Excel/PowerPoint, `.zip`, `.xml`, `.md`, and `.cmd`/`.bat` script files.
