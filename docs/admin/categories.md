# Categories

Categories are labels used to group outcomes, standards, and reporting dimensions.

## What you can do

Go to **Categories** in the admin menu to:

- View all category labels
- Create new categories
- Edit category names and descriptions
- Delete categories that are no longer needed

## How categories work

- Categories group outcomes and standards
- They appear in curriculum frameworks and reports
- Consistent category management keeps reporting clear

## Workflow

1. Review existing categories
2. Add categories needed by your curriculum framework
3. Update labels or descriptions as needed
4. Remove obsolete categories
