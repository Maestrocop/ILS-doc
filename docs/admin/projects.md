# Projects

Use the Projects page to create and manage project-based learning activities and student work.

## What you can do

Go to **Projects** in the admin menu to:

- View all projects
- Create new project assignments
- Edit project details, instructions, and due dates
- View project status and student submissions

## Workflow

1. Open Projects
2. Review existing projects
3. Create or edit project definitions
4. Link projects to the appropriate course or class

## How projects work

- Projects support longer-form learning activities
- Projects can include tasks, submissions, and artifacts
- Projects complement assignment and quiz workflows
