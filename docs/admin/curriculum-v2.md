# Curriculum Composer V2

Curriculum Composer V2 is the next-generation course blueprint editor.

## What you can do

Go to **Curriculum V2** in the admin menu to:

- Design course blueprints
- Create and edit course periods with unlimited nesting
- Map modules into specific course period slots
- Apply reusable period templates to courses
- Replace existing course period structures

## Key concepts

- **Course blueprint** — the planned sequence of modules, periods, and learning blocks for a course
- **Recursive period structure** — course periods can contain sub-periods and module slots at any depth
- **Template application** — reusable period templates can be applied to a course blueprint
- **Course-specific configuration** — the editor operates on a course-level plan that can later be assigned to classes

## How it works

1. Select or switch between courses in the blueprint workspace
2. Edit course periods and nested sub-periods
3. Map modules into specific period slots
4. Apply reusable period templates if available
5. Replace existing structures when needed
