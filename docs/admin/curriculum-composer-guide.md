# Curriculum Composer — Admin User Guide

The Curriculum Composer is the primary tool for setting up a course before classes start. Use it to define period structure, assign modules to periods, and link classes to the curriculum.

## When to use this page

Use the Curriculum Composer when:

- Setting up a course for the first time
- Defining the period/block structure for an academic year
- Assigning modules to periods in bulk
- Linking one or more classes to the course curriculum

Use the Class Setup page only to add or remove individual modules from a specific class after the curriculum is already in place.

## The 5 steps

### Step 1 — Select a course

Choose the course to configure from the dropdown. The Composer loads the existing structure for that course if present.

### Step 2 — Periods

Define time blocks for the course (Year → Block → Week).

Controls:

- **+ Add period** — type a name (e.g. `Blok 1`) and press Enter or click Add
- **Apply template** — insert a pre-built period structure (e.g. `Year-1 Periods N-4`)
- **Edit / Delete** — hover a period to rename or remove it

**Note:** Composer displays course-specific periods. Institution calendar periods are not displayed as course teaching blocks.

### Step 3 — Modules

Assign modules from the library (left) to course periods (right).

Library controls:

- **Modules / Projects tabs** — switch libraries
- **Search field** — filter by name
- **This program only pill** — toggle to show modules from all programs
- **Assign to classes pill** — when ON (default), adding a module also adds it to all active classes of this course; when OFF, the module is added to the course structure only

Period controls:

- Click a period to set the active destination (the "Adding to" indicator shows it)
- Click **+** on a module to add it to the active period
- Drag to reorder modules within a period
- Click **×** on a placed module to remove it

**Tip:** Set up periods first; the right panel is empty without periods.

### Step 4 — Classes

Link classes to the course curriculum:

- Active classes appear in the list; toggle a class ON to connect it to the curriculum
- Linked classes receive modules when **Assign to classes** is ON at the moment a module is added

**Note:** The **Assign to classes** flag acts only when you add a module—it does not retroactively assign or remove modules.

### Step 5 — Review

Verify periods, assigned modules, and linked classes in the summary view. Confirm and Save.
