# Teacher Dashboard

The Teacher Dashboard provides an overview of teacher activity and roster assignments.

## What you can do

Go to **Teacher Dashboard** in the admin menu to:

- View teacher performance and engagement metrics
- Inspect current roster assignments and teacher workload
- Support teacher staffing and coaching decisions
- Monitor teacher-facing activity in the system

## Workflow

1. Open Teacher Dashboard
2. Review teacher summaries and engagement indicators
3. Use insights to inform staffing and coaching decisions
