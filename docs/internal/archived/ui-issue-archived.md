# Class Setup Curriculum Tab — Help Tip

## What changed

The Class Setup → Curriculum tab now displays a helpful tip that directs admins to use the Curriculum Composer for full curriculum configuration.

## For admins

When you open **Class Setup → Curriculum**, you'll see a tip at the top:

> **Tip**: For full curriculum setup use the **Curriculum Composer**. This page is a quick-add for single-module changes.

Click the link to open the Curriculum Composer for your course.

### When to use Class Setup
- Quick addition of a single module to a class
- Minor curriculum tweaks for one specific class

### When to use Curriculum Composer
- Full curriculum design and structure
- Setting up periods and teaching blocks
- Configuring learning outcomes and rubrics for modules
- Bulk curriculum changes across multiple classes
