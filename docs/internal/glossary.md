# Glossary — Starter Terms

This glossary captures canonical product terms and recommended usage for documentation writers.

- Data Exchange: Unified hub for Export / Import / Templates.
- ImportShell: Shared import workflow (Upload → Map → Validate → Preview → Confirm → Report).
- Outcome: A measurable learning outcome used in rubrics and reporting.
- Module: A unit of curriculum containing assignments and sessions.
- Rubric: Assessment criteria used to grade assignments.
- Snapshot: System-derived record of student outcome measurements.
- Program / Programme: Institution-level grouping of courses and classes.

Guidelines:
- Use American English spelling by default (unless institution requests otherwise).
- Keep UI labels exact where possible (match in-app wording).
- Do not translate code blocks, API payloads, or CSV headers.
