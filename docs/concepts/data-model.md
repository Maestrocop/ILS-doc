# Data Model

This page explains the big-picture design of how ILS organizes learning data.

## The two main ideas

ILS separates two main domains:

- **Curriculum structure** — courses, modules, assignments, classes, and students (the learning context)
- **Learning intelligence** — outcomes, mastery scores, and progress trends (the measurement)

The curriculum structure provides the context. The intelligence domain provides the measurement.

## What gets measured

When students complete work:

1. An assignment is graded using a rubric
2. The rubric measures performance against learning outcomes
3. The system records mastery scores for each outcome
4. Over time, those scores are tracked to show progress and trends

## Why this matters

This design lets ILS answer key questions for teachers:

- Which outcomes are students mastering?
- How does performance change over time?
- Which outcomes need intervention?
- Where should I focus instruction?
