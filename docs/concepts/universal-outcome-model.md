# Universal Outcome Model

The Universal Outcome Model defines a consistent way to calculate mastery across different types of student work.

## Core outcome categories

Outcomes fall into types that reflect common learning goals:

- **Applied Skills** — hands-on abilities that improve with practice
- **Knowledge** — understanding and recall measured across multiple assessments
- **Professional Practice** — workplace or field-specific competencies
- **Critical Competency** — essential capabilities demonstrated repeatedly
- **Creative / Portfolio-based** — best represented by strong sample work

## How each type is measured

Different outcome types use different calculation methods:

| Type | How it's measured |
|---|---|
| Applied Skills | Recent work weighted more heavily (improvement over time) |
| Knowledge | Average across assessments |
| Professional Practice | Weighted average (some skills count more) |
| Critical Competency | Confirmed through repeated successful demonstrations |
| Creative / Portfolio-based | Student's strongest performance |

## Why this matters

Using different approaches for different outcome types ensures:
- Skills are measured fairly across all disciplines
- Work types (internships, exams, projects) all count appropriately
- Scoring stays consistent
- Teachers can use the same system for varied learning goals

## When to override defaults

In some cases, teachers or schools may use a different calculation method for a specific outcome or course. When this happens:
- The override must be clearly labeled in the system
- Teachers should document why the change was made
- Overrides should be visible in reports and auditable

## Best practice

- Use the standard category-method mapping when possible
- Only apply custom calculations when the learning context clearly requires it
- Ensure any custom rule is clearly documented
