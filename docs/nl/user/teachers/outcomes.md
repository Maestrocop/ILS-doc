# Leeruitkomsten koppelen

Koppel rubriccriteria van opdrachten aan vastgestelde leeruitkomsten, zodat de gerapporteerde snapshots de leerresultaten van studenten weergeven.

Stappen:
- Open de opdracht → Bewerken → onderdeel `Outcomes`.
- Zoek in `Outcomes Library` en koppel relevante leeruitkomsten aan specifieke rubriccriteria.

Laatst bijgewerkt: 2026-07-08

Praktijkvoorbeeld
- Opdracht `ASSIGN-001` heeft de rubriccriteria `CRIT-1` en `CRIT-2`.
- Koppel `CRIT-1` → leeruitkomst `O-01: Problem Solving` en `CRIT-2` → leeruitkomst `O-02: Communication`.

Effect op rapporten
- Bij het beoordelen leiden scores op criteria tot afgeleide snapshots van leeruitkomsten. Je ziet deze in het dashboard `Progress`.
