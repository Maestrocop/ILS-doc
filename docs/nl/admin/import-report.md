# Import rapport — vereisten

Genereer na elke import een volledig rapport dat je kunt downloaden.

Inhoud van het rapport:
- Samenvatting met aantallen: geïmporteerd, bijgewerkt, overgeslagen en fouten
- Details per rij: `row_number`, `status` (Imported/Updated/Skipped/Error) en bericht
- Downloadbare versies in CSV- en JSON-formaat

Aandachtspunten voor de gebruikerservaring:
- Voeg waar mogelijk vanuit fouten directe links toe naar de betreffende oorspronkelijke rij in Voorbeeld.
- Sta toe dat alleen mislukte rijen opnieuw worden verwerkt (gedeeltelijke herimport).
