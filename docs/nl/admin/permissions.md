# Rechten voor Data Exchange (aanbevolen)

Aanbevelingen voor het toegangsmodel (alleen documentatie):

Wie de pagina Data Exchange ziet: `Admin` en `Designer` (standaard). Docenten en coördinatoren exporteren contextueel vanuit hun eigen pagina's.

Rechten per actie (aanbevolen):

| Actie | Superadmin / Admin | Designer | Coordinator | Teacher |
|---|---:|---:|---:|---:|
| Studenten exporteren | ✓ | — | ✓ (eigen programma) | — |
| Modules exporteren | ✓ | ✓ | — | — |
| Opdrachten exporteren | ✓ | ✓ | — | — |
| Leeruitkomsten exporteren | ✓ | ✓ | — | — |
| Rubrics exporteren | ✓ | ✓ | — | — |
| Cijfers exporteren | ✓ | — | ✓ (eigen programma) | ✓ (eigen klas) |
| Studenten importeren | ✓ | — | — | — |
| Modules importeren | ✓ | ✓ | — | — |
| Opdrachten importeren | ✓ | ✓ | — | — |
| Leeruitkomsten importeren | ✓ | ✓ | — | — |
| Cijfers importeren | ✓ | — | — | — |
| Templates beheren | ✓ | ✓ | — | — |

Opmerkingen:
- Het importeren van aanwezigheid wordt sterk afgeraden, omdat dit operationele gegevens zijn die direct worden bijgewerkt. Alleen exporteren.
- Cijfers importeren is alleen toegestaan voor beheerders (scenario's voor migratie of aanvullen van gegevens achteraf).
