# How the School System Works

This document explains how the school system works in practical terms.
It is written for users who need a non-technical overview of the core education process.

## Key concepts

- **Class**: a group of students (for example, A1)
- **Module**: a subject or course unit (for example, Revit or BIM)
- **Teacher**: the person who teaches one or more modules
- **Student**: a learner who belongs to a single class

## Before the school year begins

The school prepares the curriculum and class structure before students arrive.

### Step 1 — Build the curriculum

This work is done once and can be reused each year.

- Create courses (for example: ICT – 3 years)
- Create modules (subjects)
- Define:
  - learning goals (outcomes)
  - assignments
  - grading rules (rubrics)

These items represent the content of the education program.

### Step 2 — Create classes

Create class groups such as A1, A2, or A3.
Each class is assigned:

- an academic year or period
- a campus or location

A class is a group of students that share a common schedule.

### Step 3 — Assign teaching

Define which teachers teach which modules for each class.

For example, Class A1 may include:

- Revit taught by Teacher John
- BIM taught by Teacher Sarah

A class can have multiple modules and multiple teachers.

### Step 4 — Add students

Students are accepted into the program and placed into one class.

For example:

- Ali → Class A1

Students do not choose modules directly. The modules follow the class assignment.

### Step 5 — First day of school

At the start of school:

- students know their modules
- teachers know their student groups
- rosters are complete

## Important rules

- A class is not a subject.
- A student belongs to only one class.
- Teachers teach modules inside classes.
- Students automatically take the modules assigned to their class.

## Summary

- Students are placed in a class.
- Classes contain modules.
- Teachers teach those modules.
- The school prepares the curriculum before day one.
