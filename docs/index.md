# ILS Documentation

This repository contains the user-facing and developer-facing documentation for the Intelligent Learning System.

> Live preview test: content updated on 2026-05-18.

## What this site covers

- `Developer Guide` — setup, API reference, data model, and workflows for app authors.
- `ILS Concepts` — architecture, outcome model, and the intelligence design principles.
- `Teacher Guide` — how to use the cockpit, heatmap, grading, and intervention features.
- `Admin Manual` — management pages, system settings, and operational guidance.
- `Student Manual` — student-facing progress and submission guides.
- `Management Guide` — dashboards, reporting, and thresholds.

## Repo boundaries

- `ILS-doc` is the documentation repository. All doc changes belong here.
- `ILS-dev` is the application repository. It is the source of truth for features and routes, but it must not be modified by documentation work.

## How to use this site

Start with the Developer Guide if you are documenting or reviewing the application.

If you are writing content for teachers or administrators, use the corresponding role-based guides to keep content focused on the user experience.

## Current focus

The highest priority is the Developer Guide, followed by the Teacher Guide, then Admin, Student, and Management content.
