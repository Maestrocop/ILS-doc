# Module Composer — Feature Highlight

## Why it matters

Module Composer lets teachers assemble learning sequences quickly, mixing assignments, quizzes, and projects into ordered modules with progressive unlocking to enforce prerequisite learning steps.

## Key benefits

- Faster course assembly with drag-and-drop ordering and content banks
- Guided progression: teachers can enforce prerequisite rules (must submit before advancing, must pass before continuing, etc.)
- Flexible sequencing for different pedagogical approaches

## What teachers can do

- Add content items (assignments, quizzes, projects) to a module
- Reorder items with drag-and-drop or arrow controls
- Set progression rules: whether the next item unlocks when students submit, when they're graded, or when they pass

## Suggested marketing angle

"From planning to delivery: assemble modules in minutes and ensure students follow a pedagogically sound sequence."
