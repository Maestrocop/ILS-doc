# Feature Highlights

This collection highlights the top-value features of ILS for marketing campaigns and executive summaries.

- **Module Composer** — sequencing, linked items, and progressive unlocking so teachers can build guided learning paths
- **Dashboards & Cockpits** — personalized student and teacher views for prioritized interventions and class monitoring
- **Unified Calendar** — centralized view of assignment deadlines, quizzes, class sessions, and institution events
