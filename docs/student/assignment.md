# Student Assignment

The Student Assignment page displays a single assignment to the learner.

## What the page does

This page shows the student’s assignment details, submission status, instructions, and any grading or feedback.

## Page behavior

The page typically supports:

- viewing assignment instructions and resources
- checking submission status
- seeing due dates and progress markers
- opening the submission editor or review page

## Student workflow

1. Open `/student/assignments/:assignmentId`.
2. Read the assignment instructions and expected outcomes.
3. Review any submission instructions or attached materials.
4. Follow the links to submit work or review feedback.

## Notes

- This page is a direct learner view of a single assignment.
- It is often accessed from the curriculum or submissions pages.
