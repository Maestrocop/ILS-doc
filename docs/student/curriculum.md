# Student Curriculum

The Student Curriculum page shows the learner-facing course and module structure.

## What the page does

This page helps students find their course content, modules, and the curriculum flow.
It is the student-facing view of the course structure and may include links to assignments and quizzes.

## Page behavior

The page typically supports:

- viewing enrolled courses and modules
- exploring course curriculum items
- navigating to assignments and quizzes from the curriculum view

## Student workflow

1. Open `/student/curriculum`.
2. Review the available course modules and curriculum structure.
3. Select the next module or learning activity to continue.
4. Use the navigation links to open assignments or quiz items.

## Notes

- This page is intended for learners to understand the course path.
- It may show module titles, progress indicators, and links to work items.
