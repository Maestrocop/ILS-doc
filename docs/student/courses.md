# Courses

The student Courses page is the gateway to your current learning pathway.

## What the Courses page does

The page shows the student’s current courses and modules.
It helps students find the assignments and classes they need to work on.

## Page behavior

The page typically supports:

- listing courses and associated modules
- showing progress for each course
- linking to assignments and submission workflows
- letting students choose which course work to continue

## Student workflow

1. Open `/student/courses`.
2. Select the course or module you are currently working on.
3. Review the available assignments and their due dates.
4. Navigate to the submission or dashboard views for the selected course.

## Why this matters

The Courses page is the starting point for student navigation in ILS.
It helps students stay organized around their active learning pathways.
