# Notifications

The app provides an in-app bell for important events and quick access to updates relevant to your classes and students.

## How teachers use notifications

- The bell shows recent actions like submission, grading, and returns.
- Clicking a notification opens the related student or submission detail so you can act immediately.

## Recent changes (June 2026)

- In-app notifications (bell) were introduced for submit/grade/return events. Teachers receive clearer links that take them to the relevant student submission or grading page.
- Deep-link handling improved: notification links now navigate reliably and preserve context. Long deep-link query params are cleaned from the URL after navigation for security and clarity.
