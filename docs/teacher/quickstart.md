# Teacher Quick Start

This short guide highlights the most common teacher actions.

- Quick links
- Grades export: for quick access to class grades, open the Data Exchange and go directly to the **Grades** tab: [Data Exchange Grades](../admin/data-exchange.md#grades).

	Tooltip: "Showing your classes only — contact admin to request broader access."
- Submissions & feedback: open your Class > Submissions to review and grade work

Common tasks
- Take attendance
- Grade submissions
- Open the Student Cockpit for at-risk signals
