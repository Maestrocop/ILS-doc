# Module Sequencing

This page explains best practices for ordering content, locking sequences, and preparing modules for delivery.

## Principles

- Sequence learning from simple → complex.
- Lock prerequisite content where necessary to ensure students complete foundations before advanced topics.
- Use `weeks` or `topics` to group related sessions.

## Creating a Sequence

1. Within the Module Composer, open the `Weeks & Topics` panel.
2. Add sections in the intended teaching order.
3. For each lesson, set prerequisites by selecting earlier lessons or outcomes.
4. Use the **Lock** control to prevent students from accessing future lessons until prerequisites are met.

## Examples

- Example 1: Topic A → Topic B → Topic C (linear sequence with lock after A and B)
- Example 2: Module split into two parallel strands (Theory, Practice) with a final integrative assignment

## When to Lock

- Lock when mastery of an outcome is required before moving on.
- Avoid locking lightly — overuse can frustrate learners.
