# Calendar & Events (Teacher Guide)

## What the calendar shows

The calendar aggregates all events relevant to your class:
- Assignment due dates and open dates
- Quiz and exam dates
- Custom events you create
- Institution-wide calendar items (holidays, semester dates, etc.)

## Your calendars

### Class Calendar

Shows all events for a specific class:
- Student assignment due dates
- Assessments scheduled for the class
- Teacher-created class events
- Institutional calendar items (e.g., holidays)

### Teacher Calendar

Shows your personal calendar plus events from all your classes:
- Personal calendar events you create
- All events from classes you teach
- Institutional holidays and dates

## How to add a custom event

1. Open the **Class Calendar** or **Teacher Calendar**
2. Click **Add Event** (or the "+" button)
3. Fill in the event details:
   - **Title** (required) — e.g., "Review session", "Assessment retake"
   - **Date and time** (required)
   - **Description** (optional) — additional details for students
   - **Location** (optional) — classroom or meeting link
   - **Repeat** (optional) — set daily, weekly, monthly, etc.
4. Save

The event will appear on the calendar and be visible to your students.

## Event types you'll see

- **Assignment due** — assignment deadline
- **Assignment open** — when students can start
- **Quiz/exam** — scheduled assessment
- **Custom event** — events you or other teachers created
- **Institutional** — holidays, semester start/end, registration periods

## Tips

- Use custom events to block time for reviews, retakes, or special sessions
- If your institution has holidays set in the Academic Calendar, they'll appear automatically
- You can filter the calendar view by class to focus on a specific group
