# Delivery Examples

Practical examples of module delivery and session planning.

## Example: Three-Week Project Module

Week 1 — Foundations
- Session 1: Intro & objectives (outcomes: O1)
- Session 2: Skills workshop (practice tasks)

Week 2 — Application
- Session 3: Group work (formative assessment)
- Session 4: Checkpoint & feedback (outcomes: O1, O2)

Week 3 — Synthesis
- Session 5: Final project work
- Session 6: Presentations & grading (summative assessment)

## Example: Flipped Classroom

1. Pre-class: students review recorded lecture (resource link)
2. In-class: active problem-solving and application
3. Post-class: reflective submission and rubric-based feedback
