# Teacher Manual

This guide explains how teachers use the ILS system to monitor student progress, grade work, and prioritize intervention.

## Teacher workflow

The typical workflow follows this cycle:
**Student Cockpit** → **Heatmap** → **Classroom Intelligence** → **Grading** → **Interventions**

## What teachers will find here

- **Student Cockpit:** how to read the classroom overview and student status indicators.
- **Heatmap:** how to interpret outcome mastery across the class.
- **Classroom Intelligence:** how to turn mastery patterns into actionable insights.
- **Grading & Rubrics:** how rubric scoring creates the evidence behind the reports.
- **Teacher Roster:** how to view assigned classes and student activity for teacher triage.
- **Calendar:** how to manage class and personal events, deadlines, and scheduling context.
- **Interventions:** how to choose a teaching response based on class patterns.
- **FAQ:** answers to common teacher questions about ILS workflows.

## How to use this guide

Start with the Student Cockpit page to understand the main teacher dashboard.
Then use Heatmap and Classroom Intelligence to interpret outcome patterns and recommended actions.
Use Grading to update evidence, and Interventions and FAQ for practical decision support.

Use Calendar when planning class pacing, verifying assignment/quiz due dates, or adding custom class events.



## Teacher purpose

The teacher guide is designed for classroom leaders who need to:

- identify which students and outcomes need attention
- understand how mastery and trends are calculated
- make intervention decisions based on evidence
- communicate progress clearly to students and parents
