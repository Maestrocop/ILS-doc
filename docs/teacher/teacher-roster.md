# Teacher Roster

The Teacher Roster page is the teacher-facing class and student workspace in ILS.

## What the Teacher Roster does

The page helps teachers view their assigned classes and inspect student enrollment and activity.
It is designed for quick triage of students who need attention or follow-up.

## What the roster shows

Each assigned class includes:

- class name and code
- student list with enrollment status
- last activity date
- quick access to the Student Cockpit for each student

Each student row typically includes:

- student name
- student number
- cohort or class section
- enrollment status
- last submission / activity label
- a `View` button to open the Student Cockpit filtered to that student

## Teacher workflow

1. Open `/admin/my-roster`.
2. Select the class you are teaching.
3. Scan the student list for stale activity and inactive learners.
4. Use the `View` button to jump directly to the Student Cockpit for a single student.

## Why this matters

Teacher Roster is a triage workspace.
It lets teachers quickly find the students who are most stale or at risk and then move straight into the Student Cockpit for action.
