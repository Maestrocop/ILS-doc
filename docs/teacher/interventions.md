# Interventions

This guide explains how to use recommendations from Classroom Intelligence.

[Interventions Screenshot: suggested actions list with priority labels]

## Where to find interventions

Open Classroom Intelligence after the Heatmap.
That report turns class performance into a set of suggested actions.

## What triggers intervention recommendations

The recommendation list is based on classroom performance patterns.
Common triggers include:

- **Technical cluster** — many students are weak on technical outcome areas.
- **Polarized performance** — strong and weak students coexist in the same class.
- **Threshold pressure** — many students are at or below the success threshold.
- **Low evidence** — not enough graded work exists yet for a confident recommendation.

## Common intervention actions

The report may recommend one of these actions:

- **Focused modelling workshop**
  - Use when technical outcomes are weak across the class.
  - This is a guided teaching session focused on key skills.

- **Peer-supported mixed groups**
  - Use when the class is polarized.
  - This encourages stronger students to work with weaker students on structured tasks.

- **Formative reassessment**
  - Use when the class is under threshold pressure.
  - This is a short follow-up check to see whether students recover.

- **No active intervention trigger**
  - Use when no strong class-level concern is detected.
  - Continue with the current plan and monitor the next cycle.

## Explain Decisions

Classroom Intelligence includes an `Explain Decisions` toggle.
When enabled, it reveals the evidence used to generate each recommendation.
This helps teachers understand why a specific action was suggested.

## How to use the recommendations

1. Confirm the class signal in Classroom Intelligence.
2. Review supporting evidence in the Heatmap.
3. Use the Student Cockpit to identify the students driving the signal.
4. Choose the highest-priority intervention:
   - focused modelling workshop for technical weaknesses
   - peer-supported groups for polarized classes
   - formative reassessment for threshold pressure
5. Re-check the same class after the next graded cycle.

## Practical workflow

- Start with the Heatmap to identify outcome-level gaps.
- Use Classroom Intelligence to translate patterns into actions.
- Use the Student Cockpit to focus on individual students.
- Apply the recommended intervention and track the next cycle.

## What to remember

The most useful recommendations come when there is enough graded work.
If the report says there is not enough evidence, prioritize grading pending submissions first.
