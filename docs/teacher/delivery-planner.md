# Delivery Planner

Use the Delivery Planner to schedule teaching sessions, set milestones, and coordinate resources across a module.

## Quick workflow

1. Open the module you wish to plan and select **Delivery Planner**.
2. Create session entries: title, date/time, location (virtual/in-person), and expected duration.
3. Link learning objectives and outcomes to each session.
4. Assign responsible staff or guest facilitators.
5. Save and publish the session schedule — this feeds the student calendar when published.

## Replanning and makeup sessions

- To mark a session as 'Held' or 'Cancelled', edit the session and change status.
- Use **Create makeup** to schedule alternative sessions and notify affected students.

## Notifications & Resync

- Publishing a session will push it to student calendars if calendar sync is enabled.
- If calendars do not update, ask students to resync their calendar or check the integration settings.
