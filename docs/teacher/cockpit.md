# Student Cockpit

The Student Cockpit is your daily action dashboard in ILS.

## What the Student Cockpit does

It shows the highest-priority action for each student in your class, so you can focus on who needs grading, support, or follow-up first.

You have two views:
- **Teacher View** — your classes, action-focused
- **Manager / Dean View** — class-level health across multiple classes

## Filters and scope

At the top, use the filters to select:
- **Campus**
- **Period** (academic term)
- **Class**

Filters are applied automatically — no setup needed. The Cockpit also remembers filters when you navigate from the roster or class pages.

## Priority tasks

Each student is assigned one priority task, ordered by urgency:

1. **Grade submission** — ungraded work waiting for your review
2. **Intervention** — student is below campus success threshold and needs support
3. **Follow up overdue** — student has missing work but is otherwise on track
4. **Monitor** — student is borderline or showing signs of risk

## Understanding the student row

Each row shows:

- **Student** — name and student number
- **Class** — shown in Manager View
- **Avg Score** — current overall score
- **Pending** — ungraded submissions waiting for you
- **Overdue** — assignments past due with no submission
- **Last Assessed** — when the latest graded evidence was created
- **Teacher Task** — the recommended action
- **Last Active** — days since the student last submitted work
- **Risk** — status (At Risk, Borderline, Safe)

### Pending vs Overdue (What's the difference?)

- **Pending** = student submitted work → you need to grade it
- **Overdue** = student hasn't submitted → you may need to remind or extend deadline

These are different signals for different actions.

## Trend arrows

When you have enough graded evidence, a trend arrow shows next to the score:

- **↑** improving
- **↓** declining  
- **→** stable (not changing)
- **—** only one snapshot (no trend yet)

**Important**: "Stable" doesn't mean "doing well." A student can be stable at 3.3 and still be below the 6.0 target.

## Pulse cards (top of the page)

Quick counts of urgent situations:
- **At-risk students** — below campus threshold
- **Inactive students** — haven't submitted in a while
- **Pending grades** — submissions waiting for you
- **Classes flagged** — classes with issues
- **Total classes** — classes you teach

## Manager View

In Manager View, you see a class health table with:
- Class code and campus
- Student count  
- At-risk count
- % below threshold
- Pending submissions
- Class health indicator
- Quick links to Heatmap and Classroom Intelligence

## Student Intelligence Panel

Click any student row to open the **Student Intelligence Panel**. It shows:

- Current score and trend
- Pending and overdue counts
- Outcomes where the student is weakest
- Whether the student is improving, stable, or declining
- A warning if a good overall score hides a critical weakness in one outcome
- Link to the class Heatmap

## Recommended workflow

1. **Open Student Cockpit** in Teacher View
2. **Select your class**
3. **Filter for urgent students** (Grade submission first, then Intervention)
4. **Click a student row** to open the Intelligence Panel
5. **Review the student story**, then choose your next action:
   - Grade pending work
   - Support a struggling student
   - Follow up on missing assignments
   - Monitor borderline students
