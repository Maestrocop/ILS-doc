# Teacher Guide

This guide helps teachers manage courses, create modules and assignments, grade student work, and use learning outcomes.

Getting started
- Access your course: open the `Courses` menu and select your course.
- Create a Module: click `New Module`, add title, dates, and learning objectives.

Assignments
- Create assignment: `Assignments` → `New Assignment` → fill title, due date, rubric.
- Attach rubric: choose an existing rubric or create a new one; link assignment outcomes to rubric criteria.

Grading
- Open Gradebook: `Course` → `Gradebook`.
- Enter grades: inline grading per student or bulk upload via `Data Exchange` → `Import`.
- Feedback: attach files and comments; notify students when grades are published.

Import / Export
- Export roster or grades: `Data Exchange` → `Export` → choose CSV template.
- Import outcomes or grades: `Data Exchange` → `Import` → follow ImportShell flow (Upload → Map → Validate → Preview → Confirm).

Outcomes mapping
- Map assignment criteria to declared outcomes when creating/editing assignment.
- Use `Outcomes Library` to search and link global outcomes.

Common tasks & FAQs
- How to re-open submissions: from assignment settings toggle `Accept late` or `Allow resubmissions`.
- Help: contact your coordinator or see `Internal > Help & Support`.
