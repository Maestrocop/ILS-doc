# Teacher FAQs

- Q: How do I allow late submissions? A: Assignment settings → `Allow late`.
- Q: How to bulk upload grades? A: Use `Data Exchange` → `Export` to get template, edit CSV, then `Import`.
- Q: In the grading screen, what's the difference between **Save Grade** and **Return for revision**, and do students get notified? A: Both notify the student. **Save Grade** finalizes the score (submission becomes `graded`) and the student gets a "Your work has been graded" notification. **Return for revision** sends it back to the student (submission becomes `returned`, score cleared to pending) with a "Your work has been returned — please review the feedback and resubmit" notification.
