# Outcomes Mapping

Link assignment rubric criteria to declared outcomes so reported snapshots reflect student learning.

Steps:
- Open assignment → Edit → `Outcomes` section.
- Search `Outcomes Library` and link relevant outcomes to specific rubric criteria.

Last updated: 2026-07-08

Practical example
- Assignment `ASSIGN-001` has rubric criteria `CRIT-1` and `CRIT-2`.
- Link `CRIT-1` → Outcome `O-01: Problem Solving` and `CRIT-2` → Outcome `O-02: Communication`.

Effect on reports
- When grading, criterion scores produce derived outcome snapshots visible in `Progress` dashboard.
