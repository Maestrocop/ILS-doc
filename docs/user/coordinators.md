# Coordinator Guide

This guide covers program setup, assigning teachers, running cohort reports, and managing notifications.

Managing programs
- Create or edit a program: `Admin` → `Programs` → `New Program`.
- Enrol students in cohorts and assign program coordinators.

Assigning teachers
- Use `Program Settings` → `Manage Teachers` to add or remove teacher roles for a program.

Cohort reports
- Generate cohort reports: `Reports` → choose `Cohort` → select date range and modules.

Notifications & escalations
- Configure reminder rules under `Notifications` → set thresholds for late work and interventions.
