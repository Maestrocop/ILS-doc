# Submitting Assignments

Open assignment → `Submit` → attach files → confirm. Check submission timestamp in the confirmation dialog.

If resubmissions allowed, use `Resubmit` and include explanation.

Last updated: 2026-07-08

Troubleshooting
- Upload failures: check file size limits and allowed file types.
- Late submissions: system records timestamp; late policies are enforced by assignment settings.
